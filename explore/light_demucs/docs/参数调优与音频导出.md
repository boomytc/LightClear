# Demucs 参数调优与音频导出指南

本指南记录 Demucs 在推理分离与音频导出阶段的参数机制、底层默认值与工程注意事项。

---

## 1. 推理参数与行为说明

在调用 `demucs.api.Separator` 时，本模块与上游底层各参数的定义如下：

```python
from demucs.api import Separator

separator = Separator(
    model="htdemucs",
    repo=MODEL_REPO,
    device="cpu",      # 上游默认: cuda (若可用) 否则 cpu；本仓库强制用 "cpu"
    shifts=1,          # 随机时移等变平均 (TTA)，上游默认 1
    overlap=0.25,      # 切片重叠率，上游默认 0.25
    split=True,        # 是否切块处理，上游默认 True
    segment=7,         # 切块时长 (秒)，上游模型类默认 10；本仓库 demo/产品显式用 7
    jobs=0,            # CPU 并行 worker 数，上游默认 0 (串行)
)
```

### 参数详解与对比

| 参数 | 上游 API 默认值 | 本仓库约定值 | 行为与调优说明 |
| :--- | :--- | :--- | :--- |
| `device` | `"cuda" if th.cuda.is_available() else "cpu"` | `cpu` / `mps` / `cuda:0`（按 demo 子目录） | **计算设备**：三个硬件路径均已完成实测核验（`shifts=0` 下 MPS 与 CPU 最大误差 ≤ `1.08e-5`、无 NaN，上游已在 `spec.py`/`htdemucs.py` 内对 MPS 复数 STFT 做 CPU 回退）。Apple M4 Pro 上 MPS 相对 CPU 提速约 3.1x–3.4x；Colab L4 CUDA 相对 CPU 提速约 8.6x–9.9x，峰值显存约 `0.55–0.77 GiB`。产品 `vocal_isolate_web` 仍以确定性配置为准。 |
| `shifts` | 1 | 1（demo/产品） | **时移等变增强 (TTA)**：在 0 到 0.5 秒内对音频施加随机时间偏移并在逆偏移后平均预测结果。增加 shifts（如 8）可将 SDR 提升约 0.2 dB，但耗时呈线性倍增（$N\times$）。 |
| `overlap` | 0.25 | 0.25 | **切块重叠比例**：跨 segment 拼接淡入淡出比例。增大到 0.5 可进一步平滑拼接点瞬态伪影，略增计算量。 |
| `segment` | `None` (模型类为 10) | 7 | **分段时长（秒）**：每次送入模型的音频块长度。显式设为 `7` 可降低 CPU 内存峰值与显存占用。 |
| `split` | True | True | **分块开关**：长音频必须为 True，避免全曲单次前向导致内存/显存溢出。 |
| `jobs` | 0 | 0 | **并行线程数**：**`jobs=0` 表示单线程串行处理**（使用 `DummyPoolExecutor`）。仅当 `jobs > 0` 且 `device=="cpu"` 时才会启动 `ThreadPoolExecutor(jobs)` 多线程加速。 |

## 2. 音频防削波机制 (`clip`)

在分轨重组伴奏（如 `accompaniment = drums + bass + other`）时，多轨相加的波形幅值可能超出 $[-1.0, 1.0]$ 区间导致数字硬削波（Clipping 爆音）。

### 底层实现

Demucs 的 `demucs.audio.save_audio` 函数签名已在底层内置了防削波机制：

```python
def save_audio(wav: torch.Tensor,
               path: tp.Union[str, Path],
               samplerate: int,
               bitrate: int = 320,
               clip: tp.Literal["rescale", "clamp", "tanh", "none"] = 'rescale',
               ...):
```

- **库默认即为 `clip="rescale"`**：日常调用 `save_audio(wav, path, samplerate=...)` 时无需显式传递 `clip`。实现是 `wav / max(1.01 * peak, 1)`：峰值 ≤ `1/1.01`（约 0.990）时除数为 1，波形不变；超过则整体除以 `1.01 * peak`，写入前峰值落在约 0.990，避免 PCM 硬削波。这不是听感限幅。demo 与产品都不必再传 `clip="rescale"`。
- `clamp`：硬截断至 $[-0.99, 0.99]$。
- `tanh`：双曲正切软压缩。
- `none`：不处理。

## 3. 音频导出格式与 MP3 压缩

`demucs.api.save_audio` 支持根据输出文件后缀自动选择编码器：

- **`.wav`**：根据 `bits_per_sample`（默认 16）或 `as_float=True` 保存为 PCM / Float WAV。
- **`.mp3`**：内置 `lameenc` 编码器，支持 `bitrate`（默认 320kbps）和 `preset`（默认 2，最高质量）。
